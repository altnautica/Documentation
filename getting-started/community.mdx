ADOS is built by a small team and a community of drone builders, pilots, researchers and developers. Here is where to find us.

## Discord

Discord is the main place for day-to-day conversation: quick questions, debugging help, feature discussion and sharing builds. Extension authors have their own channel.

## GitHub

Each repository has its own issue tracker. Open an issue in the repository the problem affects:

| Repository | Issues for |
|---|---|
| [ADOSMissionControl](https://github.com/altnautica/ADOSMissionControl/issues) | Mission Control in the browser or desktop app |
| [ADOSDroneAgent](https://github.com/altnautica/ADOSDroneAgent/issues) | The agent on drones, ground stations and workstations |
| [ADOSExtensions](https://github.com/altnautica/ADOSExtensions/issues) | First-party extensions |
| [ADOS-MCP](https://github.com/altnautica/ADOS-MCP/issues) | The MCP server |
| [ADOSAndroidGCS](https://github.com/altnautica/ADOSAndroidGCS/issues) | The Android GCS |
| [Documentation](https://github.com/altnautica/Documentation/issues) | Something wrong or missing on this site |

A useful bug report includes:

1. What you expected to happen
2. What happened, with exact error messages, screenshots or logs
3. Numbered steps to reproduce
4. Your environment: OS, browser, flight controller firmware, agent version and board

"It doesn't work" is hard to act on. "Arming ArduPilot Copter over WebSerial in Chrome shows `PreArm: Need 3D Fix` with 12 satellites in view" is something we can fix.

To send code, read [Contributing](/getting-started/contributing) first.

## Where to ask what

| Question | Best place |
|---|---|
| "How do I...?" | Discord |
| "Is this a bug or am I doing it wrong?" | Discord first, then a GitHub issue if confirmed |
| Bug report with steps to reproduce | GitHub issue in the affected repository |
| Feature request with a use case | GitHub issue in the affected repository |
| Flight controller firmware behaviour | Discord first; the firmware projects also run their own communities |
| Security vulnerability | Email [team@altnautica.com](mailto:team@altnautica.com), not a public issue |
| Anything else | Email [team@altnautica.com](mailto:team@altnautica.com) |

## Getting help quickly

The more specific you are, the faster someone can help.

**Good question:**

> I installed the Drone Agent on a Raspberry Pi 4B running Raspberry Pi OS Lite 64-bit. `ados status` shows `ados-mavlink` failed. The flight controller is connected over USB. Here is the output of `journalctl -u ados-mavlink -n 30`.

**Hard to answer:**

> The agent doesn't work. Help?

Include what you tried, the exact errors, your hardware (board, flight controller, camera, radio), software versions (`ados status --json`, browser and firmware versions) and relevant logs. For a structured path through common faults, see [Troubleshooting](/operations/troubleshooting).

## Stay updated

- **GitHub releases.** On each repository choose **Watch**, then **Custom**, then **Releases** to be notified of new versions. Release notes describe what changed.
- **YouTube.** Technical videos at [@altnautica](https://www.youtube.com/@altnautica).
- **LinkedIn.** Release highlights at [linkedin.com/company/altnautica](https://www.linkedin.com/company/altnautica/).

## Community guidelines

1. **Be respectful.** No personal attacks and no gatekeeping.
2. **Be specific.** Include context with every question.
3. **Search first.** The docs, GitHub issues and Discord history may already have the answer.
4. **Share back.** If you solve something, post the solution for the next person.
5. **Stay on topic.** No spam or self-promotion unrelated to drones or ADOS.

Built something with ADOS? Share it on Discord.
