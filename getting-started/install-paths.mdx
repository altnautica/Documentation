What you install depends on what you are building.

| You have | Install |
|---|---|
| A flight controller and a laptop | Only [Mission Control](/mission-control/installation). Connect over USB. |
| A drone with a companion computer | Mission Control, plus the Drone Agent on the companion computer. |
| A long-range video link | All of the above, plus the Ground Agent on a ground station. |
| A laptop, desktop or GPU box to run heavy jobs for the fleet | The agent with the `workstation` or `compute` profile. See [Node profiles](/getting-started/node-profiles#the-four-profiles). |

## Install the agent on a board

The Drone Agent and the Ground Agent are the same software installed with a different profile. The install script needs a board already running its vendor Linux image with SSH enabled. Release binaries are published for 64-bit ARM (aarch64). An x86_64 Linux box needs an installer built from source (see [Install the Drone Agent](/drone-agent/installation)), and 32-bit images are not supported.

<Steps>
  <Step title="Boot the board on its vendor OS">
    Flash the vendor's 64-bit image with the vendor's own imaging tool, boot it, and make sure you can reach it over SSH. On a Raspberry Pi, use Raspberry Pi OS Lite (64-bit).
  </Step>
  <Step title="Run the install command over SSH">
    For a drone:

    <InstallAgent />

    For a ground station:

    <InstallGroundAgent />

    Without `--profile`, a fresh install becomes a drone. The board is detected automatically.
  </Step>
  <Step title="Finish setup and pair">
    Open the agent's dashboard at `http://<board-ip>:8080/` to finish setup, then pair the node with Mission Control. It then appears in the Mission Control fleet.
  </Step>
</Steps>

<Tip>
The Flash Tool in Mission Control is an optional shortcut. Open **Flash Tool**, pick **ADOS Drone Agent** or **ADOS Ground Agent** as the stack, pick your board, and click **Copy** to get the same install command with the right profile.
</Tip>

For the full walkthroughs, see [Install the Drone Agent](/drone-agent/installation) and [Install the Ground Agent](/ground-agent/installation). Supported boards are listed in [Supported hardware](/drone-agent/supported-hardware).

## Flash flight controller firmware

The Flash Tool also flashes flight controller firmware. That is a separate flow from installing the agent: it runs in the browser and needs a Chromium-based browser (Chrome, Edge, Brave or Opera) for WebUSB and WebSerial, or the desktop app. See [Flash Tool](/mission-control/flash-tool).
