## A software-defined drone platform

Altnautica ADOS is an open-source software stack for drones. It covers the aircraft, the ground and the fleet: software on the drone's companion computer, a ground station node for long-range video, a ground control station that runs in your browser, and the extensions, SDKs and AI tooling that build on them.

You do not need a specific drone. ADOS works with flight controllers running ArduPilot, PX4, Betaflight or iNav. Add a companion computer (a Raspberry Pi, a Radxa board, or another Linux SBC), install the agent, and the drone gains video streaming, a REST API, an extension host, cloud relay and one-command updates.

## How they fit together

The flight controller runs the autopilot firmware. The companion computer runs the Drone Agent. On the ground, a small SBC runs the Ground Agent. Mission Control runs in your browser, the desktop app or on Android.

```mermaid
flowchart LR
    subgraph Drone
        FC[Flight Controller<br/>ArduPilot / PX4 / Betaflight / iNav]
        CAM[Camera]
        SBC[Companion SBC<br/>Drone Agent]
        RADIO_TX[WFB-ng TX<br/>RTL8812EU]
    end

    subgraph Ground
        RADIO_RX[WFB-ng RX<br/>RTL8812EU]
        GS[Ground Station SBC<br/>Ground Agent]
    end

    subgraph You
        BROWSER[Browser<br/>Mission Control]
        PHONE[Phone / Tablet]
        MONITOR[HDMI Monitor]
    end

    FC <-->|MAVLink / MSP| SBC
    CAM -->|USB / MIPI CSI| SBC
    SBC -->|H.264 / H.265 video| RADIO_TX
    RADIO_TX -.->|5.8 GHz WFB-ng| RADIO_RX
    RADIO_RX --> GS
    GS -->|WiFi AP / USB tether| BROWSER
    GS -->|WiFi AP| PHONE
    GS -->|HDMI| MONITOR
    SBC -->|4G LTE / WiFi| BROWSER
```

Link range depends on the antennas: expect 1-3 km line of sight with stock antennas, and more with a high-gain ground dish. See [WFB-ng](/drone-agent/wfb-ng).

<Note>
You do not need every product at once. Mission Control works on its own with a USB cable to your flight controller. The Drone Agent works on its own over WiFi or a 4G modem. The Ground Agent is only needed for long-range WFB-ng video.
</Note>

## Who is this for?

**FPV builders and pilots.** You already have a drone and want strong configuration tools, mission planning and a GCS that runs in your browser.

**Researchers and engineers.** You need a programmable platform with a REST API, SDKs in Python, Rust and TypeScript, and AI access over MCP.

**Commercial operators.** You run mapping, inspection or agriculture missions and need reliable planning, fleet telemetry and room to customise.

**Students and educators.** You want to learn how drones work at every layer. ADOS is open source and documented.

**Hardware integrators.** You build drone hardware and want an open software stack on it. The agent ships 21 board profiles.

## What you can do today

### Mission Control
- Connect to ArduPilot, PX4, Betaflight or iNav over WebSerial (USB in the browser), WiFi or the cloud
- 87 flight controller configuration panels: failsafe, PID tuning, power, OSD, ports, sensors, gimbal, LED, CAN, VTOL and more
- Calibration wizards for accelerometer, gyro, compass, level, RC, ESC, airspeed, barometer and CompassMot
- Mission planning with 9 pattern generators: survey grid, orbit, corridor scan, expanding-square search, sector search, parallel track, structure scan, fixed-wing landing and VTOL landing
- 3D mission simulation, geofence and rally points
- Gamepad and HOTAS flight control, live WebRTC video and a first-person cockpit
- Firmware flashing over WebSerial
- Demo mode with a fourteen-aircraft simulated fleet, so you can try it with no hardware

### Drone Agent
- One-line install on any supported SBC
- Auto-detects the board and the flight controller
- Video pipeline from camera to H.264/H.265 over WFB-ng or WebRTC
- REST API on port 8080, served by a native Rust front
- Setup webapp for onboarding, MAVLink, video, network and remote access
- A live [terminal dashboard](/drone-agent/tui-dashboard) (`ados`) and CLI groups for config, diagnostics, hardware, logs, MCP, network, plugins, profile, radio and recording
- Signed extensions with SDKs for Python, Rust and TypeScript
- 21 board profiles, from Raspberry Pi to Rockchip, Allwinner, Jetson and generic x86_64
- One-command updates with `ados update`

### Ground Agent
- Same install script, auto-detects ground-station hardware
- Receives WFB-ng video and relays it to browsers over WebRTC
- WiFi access point and USB tether (CDC-NCM) for laptops and phones
- Physical UI: OLED display and buttons, plus an optional 480x320 touch LCD
- HDMI kiosk mode for field use with a monitor and gamepad
- MeshNet relay and receiver roles for multi-node ground networks
