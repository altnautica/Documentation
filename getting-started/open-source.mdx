ADOS is built in public repositories. You can read every line that runs on your drone, fix it, extend it and run it on the hardware you choose.

## Repositories

| Repository | What it is | Licence |
|---|---|---|
| [ADOSMissionControl](https://github.com/altnautica/ADOSMissionControl) | Mission Control, the browser and desktop ground control station (TypeScript, Next.js, Electron) | GPL-3.0-only |
| [ADOSDroneAgent](https://github.com/altnautica/ADOSDroneAgent) | The agent for every profile: drone, ground station, workstation and compute (Rust and Python) | GPL-3.0-or-later |
| [ADOSExtensions](https://github.com/altnautica/ADOSExtensions) | The first-party extensions | GPL-3.0-or-later |
| [ADOS-MCP](https://github.com/altnautica/ADOS-MCP) | The MCP server that connects AI assistants to ADOS nodes | MIT |
| [ADOSAndroidGCS](https://github.com/altnautica/ADOSAndroidGCS) | The Android GCS (Kotlin, Jetpack Compose) | GPL-3.0-only |
| [Documentation](https://github.com/altnautica/Documentation) | This documentation site | CC0 1.0 Universal |

The Ground Agent is not a separate repository. It is the agent installed with the `ground_station` profile.

The agent's MAVLink router is native Rust; its Python helpers use pymavlink. For how the code in each repository is laid out, see [Project structure](/architecture/project-structure).

## What GPLv3 means for you

| You can | Details |
|---|---|
| Use it for any purpose | Personal, educational, research or commercial. |
| Read and modify the source | Fork it, patch it, extend it. |
| Distribute copies | Share it with anyone. |
| Distribute modified versions | Ship your own version. |

| You must | Details |
|---|---|
| Keep it GPLv3 | Modified versions you distribute are also GPLv3. |
| Provide the source | If you distribute binaries, make the corresponding source available. |
| State changes | Note what you changed. |

You cannot release GPLv3 code under a closed licence or add restrictions beyond what GPLv3 allows.

<Note>
GPLv3 does not prevent commercial use. You can sell drones running ADOS, and you can charge for support, customization and integration. You cannot close the source.
</Note>

## MIT: the MCP server

ADOS-MCP is under the MIT licence. You can use, modify and redistribute it, including in closed-source software, as long as you keep the copyright and licence notice.

## CC0: documentation and hardware designs

This documentation and the ADOS hardware designs (schematics, PCB layouts, mechanical drawings, enclosures and printable accessories) are dedicated to the public domain under **CC0 1.0 Universal**. You can copy, modify, manufacture and sell them with no obligation to credit Altnautica or share your changes.

## Running without Altnautica infrastructure

Mission Control works with no backend: connect over USB, plan, fly and configure with no account and no internet. The agent works with no cloud: the cloud relay is off until you turn it on. To run the cloud features on your own servers, see [Self-hosting](/developers/self-hosting/overview).

Mission Control works alongside other MAVLink ground control stations on the same vehicle.

## FAQ

**Can I use ADOS commercially?**
Yes. GPLv3 allows commercial use. If you distribute modified versions, those must also be GPLv3.

**Can I ship ADOS in a product without releasing my source?**
If you distribute ADOS, modified or not, you must provide the corresponding source under GPLv3, including your modifications. Running ADOS as a hosted service without distributing it does not trigger that requirement under GPLv3.

**Can I use parts of ADOS in a non-GPL project?**
Not the GPLv3 parts: work based on GPLv3 code must also be GPLv3. The MCP server is MIT and has no such requirement.

**Who owns the copyright?**
The original authors, Altnautica and contributors. Contributors keep the copyright on their contributions and license them under the repository's licence. There is no contributor licence agreement.
