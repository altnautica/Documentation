The Ground Agent is the ADOS agent installed with the `ground_station` profile. It receives WFB-ng video and telemetry from a drone and serves them to your laptop, phone or an HDMI monitor. By the end of this page a ground station runs its receiver and access point, and you have opened it from a browser.

## Hardware

| Component | Example | Purpose |
|---|---|---|
| Single-board computer | A board from [Ground Agent supported hardware](/ground-agent/supported-hardware) | Runs the agent |
| WFB-ng adapter | RTL8812EU USB adapter | Receives the drone's radio link |
| Antennas | Two 5.8 GHz SMA antennas | Range |
| Power | USB-C wall adapter or PD power bank | See [Power and runtime](/ground-agent/power-and-runtime) |

Optional for field use without a laptop: a small display and four buttons ([Display](/ground-agent/display)), an HDMI monitor ([HDMI kiosk](/ground-agent/hdmi-kiosk)) and a USB gamepad.

The drone needs the Drone Agent with a matching WFB-ng adapter. See [Quickstart: Drone Agent](/getting-started/quickstart-drone-agent).

## Install

Flash a 64-bit OS image for your board with SSH enabled, plug in the WFB-ng adapter, SSH in, and run:

The profile is chosen at install time, never detected from the hardware. Without `--profile ground_station` the installer opens its wizard in an interactive terminal; choose **This receives on the ground (Ground station)** on the **Role** screen. A non-interactive install with no profile installs a drone.

Mission Control's [Flash Tool](/mission-control/flash-tool) can also show the command: pick the Ground Agent stack and your board. Its command already carries the ground profile flag. Board-specific steps are on [Install the Ground Agent](/ground-agent/installation).

## Verify

```bash
ados status
journalctl -u ados-wfb-rx -n 30 --no-pager
```

`ados status` shows the node name, the `ground_station` profile and the addresses the node answers on. `ados-wfb-rx` is the WFB-ng receiver unit. Once a drone is paired and in range, `ados diag link` reports whether the link is healthy. The full unit list for this profile is on [systemd services](/drone-agent/systemd-services).

If you fitted a display, its link stats page shows the radio link, decoder and system state:

## Connect a laptop or phone

1. Join the Wi-Fi network `ADOS-GS-XXXX`, where `XXXX` comes from the device ID. The passphrase is generated for each unit on first boot. Read it from the installer's completion summary, the `wifi key` row of `ados`, or `sudo ados network ap-passphrase`.
2. Open `http://192.168.4.1:8080` for the ground station dashboard, or `http://192.168.4.1:8080/cockpit/` for the on-box cockpit.

Over a USB-C data cable the same pages are at `http://192.168.7.1:8080`. See [USB tether](/ground-agent/usb-tether). For the Android app, see [Android GCS](/android/overview).

Before video appears, the ground station and the drone must be paired over the air. [Ground Agent setup](/ground-agent/setup) walks through it.
