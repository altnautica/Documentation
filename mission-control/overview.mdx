ADOS Mission Control is an open-source ground control station (GCS). It runs in a Chromium browser or as a desktop app, talks to flight controllers directly over USB, Bluetooth or the network, and manages Drone Agent and Ground Agent nodes as a fleet. You use it to fly, plan missions, configure the flight controller, flash firmware and review flight logs.

## Ways to run it

| Option | What you get |
|---|---|
| Hosted | Open [command.altnautica.com](https://command.altnautica.com). Nothing to install. |
| Desktop app | Native UDP and TCP MAVLink sockets plus device pickers for USB and serial. See [Desktop app](/mission-control/desktop-app). |
| From source | `npm run dev` or `npm run demo` on port 4000. See [Install Mission Control](/mission-control/installation). |

USB Serial and Bluetooth need Chrome or Edge, because they use the Web Serial and Web Bluetooth APIs. A demo fleet runs with no hardware at all; the full list of simulated nodes is on [Dashboard and fleet](/mission-control/dashboard#demo-fleet).

## Supported firmware

| Firmware | Protocol | Configure and fly | Flash from Mission Control |
|---|---|---|---|
| ArduPilot | MAVLink v2 | Yes | Yes |
| PX4 | MAVLink v2 | Yes | Yes |
| Betaflight | MSP | Yes | Yes |
| iNav | MSP | Yes, see the [iNav guide](/mission-control/inav-guide) for scope | No. Use iNav Configurator. |

Panel coverage per firmware is on [Firmware comparison](/mission-control/firmware-comparison).

## Tech stack

| Layer | Technology |
|---|---|
| Framework | Next.js (App Router) and React |
| Language | TypeScript |
| State | Zustand stores with ring-buffered telemetry |
| Maps | Leaflet (2D) and CesiumJS (3D mission preview) |
| Video | WebRTC (WHEP on the LAN, MQTT signalling across networks) |
| Backend | Convex, optional, for sign-in and cloud features |
| Desktop | Electron |
| License | GPL-3.0-only |
