Mission Control works with four flight controller firmware families. It detects the firmware when it connects and shows only the panels and features that firmware supports.

## Feature matrix

| Feature | ArduPilot | PX4 | Betaflight | iNav |
|---|---|---|---|---|
| Protocol | MAVLink v2 | MAVLink v2 | MSP v1/v2 | MSP v1/v2 |
| Typical use | Autonomous missions, survey, VTOL, rover, boat, sub, heli | Autonomous missions, MAVLink ecosystem integration | FPV racing and freestyle | FPV with navigation modes, fixed-wing |
| Detection | HEARTBEAT `autopilot = 3` | HEARTBEAT `autopilot = 12` | MSP `FC_VARIANT` = `BTFL` | MSP `FC_VARIANT` = `INAV` |
| Parameter access | Numeric index | Numeric index | Numeric index plus virtual parameters | Name-based settings |
| Parameter writes | Stored on set | Stored on set | Explicit save | Explicit save |
| Mission upload | Yes (MAVLink mission protocol) | Yes (MAVLink mission protocol) | No | Yes (MSP waypoints, multi-mission) |
| Mission items | 12 navigation commands and 16 attached actions | 12 navigation commands and 16 attached actions | None | WAYPOINT, POSHOLD_UNLIM, POSHOLD_TIME, RTH, LAND, SET_POI, JUMP, SET_HEAD |
| Multiple missions stored on the FC | No | No | No | Yes |
| Geofence | Polygon and circle, with zones | Polygon and circle, with zones | No | Geozones (polygon and circle, up to 10 vertices per polygon) |
| Rally points | Yes | No | No | No |
| Safehomes | No | No | No | Yes (8 slots) |
| Flight modes | Mode select over MAVLink | Mode select over MAVLink | Box modes on AUX channels | Box modes plus navigation modes |
| OSD | OSD Editor | No | OSD Editor and OSD Preview | iNav OSD, Custom OSD and OSD Preview |
| Flight logs | Download from the FC, Log Analysis | Download from the FC, Log Analysis | Blackbox | Blackbox |
| Command line | CLI | Shell (NuttShell over MAVLink) | CLI | CLI |
| Flash from Mission Control | Yes | Yes | Yes | No. Use iNav Configurator |
| LED strip | Yes | No | Yes | Yes |
| Gimbal and camera | Yes | Yes | No | No |
| MAVLink signing | Yes | No | Not applicable | Not applicable |
| VTX | No | No | Yes | Yes |
| DroneCAN | Yes | Yes | No | No |
| Stick control from a gamepad | `MANUAL_CONTROL` up to 50 Hz | `MANUAL_CONTROL` up to 50 Hz | `MSP_SET_RAW_RC` up to 50 Hz | `MSP_SET_RAW_RC` up to 50 Hz |

Stick control streams only while it is switched on, the aircraft is armed and the flight mode gives the pilot stick authority. On MSP links it overrides every RC channel. See [Cockpit and Skills](/mission-control/cockpit).

The demo fleet includes aircraft on every firmware. See [Dashboard and fleet](/mission-control/dashboard).

## Shared panels

The **Setup** tab uses one set of panels across firmwares and adapts each panel to the connected firmware. For example, **Receiver** reads RC settings from parameters on ArduPilot and PX4 and from `MSP_RX_CONFIG` on Betaflight and iNav. Panels gate on firmware capability, vehicle class and firmware type. The full list is on [Flight controller setup](/mission-control/fc-configuration).

| PX4 | **Airframe** and **Actuators** (the PX4 names for **Frame** and **Outputs**), **VTOL Transition**, **Thermal Cal**, **Flight Behavior**, **Fixed-Wing Tuning**, **Autotune**, **Control Allocation**, **Shell** |
| Betaflight | **Configuration**, **All Settings**, and with iNav: **Aux Modes**, **Motors & ESC**, **Rate Profiles**, **Adjustments**, **VTX**, **Blackbox**, **OSD Preview** (MSP DisplayPort) |
| iNav | **Navigation Config**, **iNav Mission**, **Mixer Profiles**, **Output Mapping**, **Servos (iNav)**, **FW Approach**, **Failsafe (iNav)**, **Safehome**, **Geozones**, **Battery Profiles**, **Temp Sensors**, **Control Profiles**, **MC Braking**, **Rate Dynamics**, **EZ Tune**, **Nav PID**, **iNav OSD**, **Custom OSD**, **Logic Conditions**, **Global Variables**, **Programming PIDs**, **Programming (JS)** |

## Choosing a firmware

- **Survey, mapping or delivery aircraft:** ArduPilot offers the widest feature set. iNav on a small F7 or H7 board covers many autonomous missions at lower weight.
- **FPV with position hold or return to home:** iNav.
- **FPV racing or freestyle:** Betaflight.
- **MAVLink ecosystem integration:** PX4 or ArduPilot, depending on the airframe and mission.

ArduPilot, PX4, Betaflight and iNav are all configurable and flyable from Mission Control. ArduPilot, PX4 and Betaflight are also flashable from the [Flash Tool](/mission-control/flash-tool).

## Outside Mission Control

- **Telemetry on the RC transmitter** (SmartPort, CRSF, LTM) is handled by the RC system.
- **Goggle OSD rendering** happens on the aircraft. Mission Control configures what the OSD shows, not how goggles render it.
- **Dense mapping, terrain meshes and multi-drone aggregation** live in the Drone Agent, not in Mission Control.
- **Phones:** Mission Control targets desktops, laptops and landscape tablets. For a phone, use the [Android GCS](/android/overview).
