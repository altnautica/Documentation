The **Plan** tab is the mission planner. You work on one flight plan at a time: pick or create a plan in the library, place waypoints and actions on the map, review the mission, then upload it to the flight controller.

<Frame caption="Plan tab with a loaded mission, the right panel open and the Terrain Profile expanded.">
  ![Plan tab showing a waypoint mission on the map with the Terrain Profile section open](/images/mission-control/plan-mission.png)
</Frame>

<Warning>
Uploading a mission changes what the aircraft flies in AUTO. Read [Safety](/operations/safety) before you fly a new mission.
</Warning>

## Layout

| Area | What it holds |
|---|---|
| **FLIGHT PLANS** library (left) | Saved plans and folders, search, sort (Name, Date, WPs), **New Plan**, **New Folder**, **Import**, **From Drone** |
| Tool dock (on the map) | Drawing tools, undo and redo, clear, map overlays, offline area download and shortcut help |
| Right panel, **Setup** band | **Mission Setup** (name, target drone), **Defaults** (altitude, speed, **Accept Radius**, **Altitude Frame**) |
| Right panel, **Build** band | **Copilot**, **Flight Patterns**, **Mission Templates**, **Waypoints**, **Batch Edit** (when several waypoints are selected), **Geofence**, **Rally Points**, **Points of Interest**, **Transform Mission** |
| Right panel, **Review** band | **Terrain Profile**, **Mission Validation**, site conditions (**Sun & golden hour**, **Weather**), **Energy estimate**, **Pre-flight checklist** |
| Footer | **Save Mission**, **Upload to FC**, **Simulate in 3D** and a menu with the import and export actions |
| Stats bar (bottom left of the map) | Waypoint count, total distance, estimated time, maximum altitude, average speed |

## Create a mission

<Steps>
  <Step title="Open or create a plan">
    Click **Plan** in the top navigation. Pick a plan in the **FLIGHT PLANS** library, or click **New Plan**. The map tools stay inactive until a plan is open.
  </Step>
  <Step title="Set the defaults">
    In **Defaults**, set the default altitude, speed, accept radius and altitude frame: **Relative (Home)**, **Absolute (MSL)** or **Terrain Following**. New waypoints take these values.
  </Step>
  <Step title="Place waypoints">
    Choose the Waypoint tool (`W`) and click the map. Use the Takeoff (`K`), Land (`J`), Loiter (`O`) and ROI (`R`) tools for those commands. Click a waypoint to select it; expand it in **Waypoints** to edit its command, altitude, speed and attached actions.
  </Step>
  <Step title="Review">
    Open **Mission Validation** (`I`). Issues update as you edit. Blocking issues disable **Upload to FC** and the button shows the error count. Check the **Terrain Profile** (`T`) for ground clearance.
  </Step>
  <Step title="Save and upload">
    Click **Save Mission** to store the plan in the library, then **Upload to FC**. A pill next to the buttons shows whether the plan on the aircraft matches the plan in the editor.
  </Step>
</Steps>

Right-click the map for the context menu, for example to insert a waypoint at that point.

## Commands

A waypoint's own command is always a navigation command. Actions attach to a waypoint through its action timeline.

**Navigation commands**

| Label | Behaviour |
|---|---|
| Waypoint | Fly to the point |
| Spline Waypoint | Fly a smooth curve through the point |
| Takeoff | Climb to the waypoint altitude |
| Land | Land at the point |
| Loiter (unlimited) | Hold at the point until the mission is advanced |
| Loiter (Time) | Hold for a set time |
| Loiter (Turns) | Circle a set number of turns |
| Return to Launch | Fly home |
| VTOL Takeoff | Vertical takeoff (VTOL aircraft) |
| VTOL Land | Vertical landing (VTOL aircraft) |
| Payload Place | Descend and release a payload |
| Land Start | Mark the start of a landing sequence |

**Attached actions**

| Group | Actions |
|---|---|
| Camera | `DO_SET_CAM_TRIGG`, `DO_DIGICAM`, `DO_MOUNT_CONTROL`, `ROI`, `DO_SET_ROI_NONE` |
| Movement | `DO_SET_SPEED`, `CONDITION_YAW` |
| Payload | `DO_SET_SERVO`, `DO_GRIPPER`, `DO_WINCH`, `DO_AUX_FUNCTION` |
| Flow | `DO_JUMP`, `DELAY`, `CONDITION_DISTANCE` |
| System | `DO_FENCE_ENABLE`, `DO_SET_HOME` |

<Note>
iNav flies only three attached actions: `ROI`, `DO_JUMP` and `CONDITION_YAW`. Upload to an iNav flight controller refuses any other action. See [iNav guide](/mission-control/inav-guide).
</Note>

## Terrain profile

With the **Terrain Following** frame, or to check clearance on any plan, the planner looks up ground elevation for each waypoint from the Open Elevation API and caches the results. The **Terrain Profile** section plots ground elevation against the flight path and marks legs with low clearance. Validation reports a blocking issue when clearance is too low, and an advisory when terrain could not be checked.

## Batch edit

Select several waypoints (Shift-click). The **Batch Edit** section appears with four operations: set altitude, set speed, set command, and delete the selected waypoints.

## Transform mission

**Transform Mission** moves, rotates or scales the whole mission around its centre. Relative positions and altitudes stay the same.

## Mission validation

Validation runs continuously. Blocking issues stop the upload; advisories are shown but do not.

<AccordionGroup>
  <Accordion title="Blocking issues">
    - Empty mission
    - Mission starts above the ground with no Takeoff command
    - An action used as a navigation command, or an action with no location
    - Invalid coordinates (waypoints, actions or rally points)
    - Duplicate sequence numbers
    - Altitude above the ceiling or below the minimum
    - Waypoint outside the geofence or inclusion zone, or inside an exclusion zone
    - A leg that crosses an exclusion zone
    - Invalid `DO_JUMP` target, or a jump loop with no exit
    - Terrain clearance too low
    - RTL altitude too low
    - Rally point outside the fence or inside an exclusion zone
  </Accordion>
  <Accordion title="Advisories">
    - Too few waypoints, first waypoint is not Takeoff, home not set
    - No Land or Return to Launch at the end
    - Duplicate waypoints and excessive leg distance
    - Leg or waypoint beyond the link range
    - Turn radius too tight for the aircraft
    - `DO_JUMP` that repeats forever or targets an unreachable item
    - Altitude or terrain not checked
    - Self-intersecting fence, rally point above the fence ceiling
  </Accordion>
</AccordionGroup>

The **Energy estimate** section gives a rough energy, flight-time and battery-swap figure from a default power draw. Check it against your own power curve.

## Copilot

**Copilot** sets up a mission from plain language, on the device with no network. Type a request such as `survey at 80m, 75% overlap` and click **Apply**, or click **Map this area** to run a survey over the current map view. It understands patterns, altitude, overlap and speed.

## Mission templates

**Mission Templates** build a ready-to-fly plan from the current map view, for example **Grid survey**, **Property mapping**, **Orbit inspection** and **Corridor scan**. A template uses your drawn boundary, or a box around the map centre when there is none, and asks before replacing the current plan.

## Map aids

- **Place search** (`/`) centres the map on a place.
- **Overlays** (`L`) shows KML and raster (GeoTIFF) overlays. See [File formats](/mission-control/file-formats).
- **Offline area download** in the tool dock saves map tiles for the visible area.
- **Sun & golden hour** and **Weather** in the Review band show conditions at the first waypoint.

## Import, export and download

| Action | Where |
|---|---|
| **Upload to FC** | Footer. Sends the mission over the MAVLink mission protocol (MSP on iNav) |
| **Download from Drone** | Footer menu, or **From Drone** in the library. Reads the mission stored on the flight controller |
| **Import boundary (KML/SHP)** | Footer menu |
| Export | Footer menu: `.altmission`, `.waypoints`, `.plan` (QGC), KML, `.kmz`, CSV, and a **Flight brief (PDF)** |
| **Copy share link** | Footer menu. Encodes the plan in a link; large plans need file export |
| **Import** | Library. Loads a plan file |

See [File formats](/mission-control/file-formats) for each format.
