The **Simulate** tab plays the mission that is open in the Plan tab on a 3D globe, so you can check the route, altitudes and terrain before you fly. It is a preview of the plan: it does not fly an aircraft and it never edits the mission. To run a simulated flight controller, see [SITL testing](/mission-control/sitl-testing).

## Preview a mission

<Steps>
  <Step title="Plan the mission">
    Build or open a plan in the [Plan tab](/mission-control/mission-planning). Click **Simulate in 3D** in the planner footer, or click **Simulate** in the top navigation.
  </Step>
  <Step title="Play it">
    Press `Space` or use the transport controls. A drone model flies the mission route.
  </Step>
  <Step title="Look around">
    Switch camera modes, scrub the timeline and change the speed. With an empty mission the tab shows a link back to the Plan tab.
  </Step>
</Steps>

Loading a saved plan from the library (`L`) asks first if it would replace unsaved work.

## What the globe shows

The mission path and waypoints, the fence and rally points, camera trigger points (when enabled) and the animated drone.

## Preview HUD

The HUD shows values modelled from the plan, not live telemetry, and carries a **PREVIEW** badge.

| Field | Meaning |
|---|---|
| WP | Current waypoint |
| ALT | Altitude from the plan |
| SPD | Speed from the plan |
| HDG | Heading |
| DIST | Distance flown |
| ETA | Time remaining |
| CAM | Camera trigger state |
| BATT, SIG, WIND | Shown as a dash: a preview has no battery, link or wind data |

## Simulation panel

The panel on the right holds the waypoint list, the altitude profile, the terrain profile, the active waypoint and the waypoint progress, along with the playback controls.

### Playback

Speeds are 0.25x, 0.5x, 1x, 2x and 4x. Stepping moves 1 second.

| Key | Action |
|---|---|
| `Space` | Play or pause |
| `Esc` | Stop |
| `R` | Reset playback |
| `→` / `←` | Step forward or back 1 s |
| `1` to `9` | Seek to 10% to 90% |
| `]` / `[` | Faster / slower |
| `Home` / `End` | Rewind to the start / skip to the end |
| `T` / `F` / `O` / `X` | Top-down, Follow, Orbit or Free camera |
| `L` | Toggle the plan library |

### Camera modes

| Mode | Key | View |
|---|---|---|
| Top-down | `T` | Straight down, following the drone |
| Follow | `F` | Behind the drone |
| Orbit | `O` | Circling the drone |
| Free | `X` | Move the camera yourself |

## Map controls

| Control | Options |
|---|---|
| **MAP** | **Dark** or **Sat** (satellite) basemap |
| **Quality** | **Balanced** or **High** |
| **Buildings** | 3D buildings. **Requires Cesium Ion token** |
| **Terrain** | Terrain exaggeration |
| **Labels** | Place labels |
| **Camera triggers** | Show camera trigger points |
| **Rounded turns** | Softens corners on the drawn line. Display smoothing only, not the flown path |

## Compare a flown log

**Compare a flown log** overlays the path an aircraft actually flew on the mission. Click **Choose log file** and pick a `.bin`, `.log`, `.tlog` or `.ulg` log. Nothing is drawn unless the log contains GPS-fixed positions. **Clear** removes the overlay.

To replay a recorded flight with its telemetry, use [Flight logs](/mission-control/flight-logs).

## Cesium setup

Cesium assets are served by Mission Control itself from `/cesium/`. `npm run copy:cesium` copies them from `node_modules` before `dev`, `demo` and `build`, so the globe works offline.

Terrain and 3D buildings need a Cesium Ion token. Set it as the Convex server variable `CESIUM_ION_TOKEN`:

```bash
npx convex env set CESIUM_ION_TOKEN your_cesium_ion_token
```

Without Convex, Mission Control falls back to `NEXT_PUBLIC_CESIUM_ION_TOKEN` from the build environment. Without any token the globe still renders, but terrain is flat and **Buildings** is unavailable. Get a token at [cesium.com/ion](https://cesium.com/ion). See [Installation](/mission-control/installation).

## Performance

The globe needs WebGL 2. If the frame rate drops, set **Quality** to **Balanced**, turn off **Buildings**, close other GPU-heavy tabs or shrink the window.
