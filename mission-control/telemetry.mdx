Mission Control decodes MAVLink (ArduPilot, PX4) and MSP (Betaflight, iNav) telemetry into ring-buffered stores, so memory stays bounded on long flights. The readouts live on the drone's [Flight tab](/mission-control/flight-control), the telemetry deck and the [Cockpit](/mission-control/cockpit) HUD.

## Readouts

### Position

| Readout | Source | Description |
|---|---|---|
| Altitude | `GLOBAL_POSITION_INT` / `VFR_HUD` | Relative altitude in metres |
| Speed | `VFR_HUD` / `GLOBAL_POSITION_INT` | Ground speed |
| Heading | `VFR_HUD` | Heading in degrees |
| Climb rate | `VFR_HUD` | Vertical speed in m/s |
| Latitude and longitude | `GLOBAL_POSITION_INT` | Position |

### Power

| Readout | Source | Description |
|---|---|---|
| Battery voltage | `SYS_STATUS` / `BATTERY_STATUS` | Pack voltage |
| Battery current | `SYS_STATUS` / `BATTERY_STATUS` | Current draw in amps |
| Battery remaining | `SYS_STATUS` | Percentage remaining |
| Consumed mAh | `BATTERY_STATUS` | Charge used |
| Power | Calculated | Voltage times current |
| Estimated flight time | Calculated | From current draw and remaining capacity |

### GPS

| Readout | Source | Description |
|---|---|---|
| Fix type | `GPS_RAW_INT` | No fix, 2D, 3D, DGPS, RTK float, RTK fixed |
| Satellites | `GPS_RAW_INT` | Satellites in use |
| HDOP | `GPS_RAW_INT` | Horizontal dilution of precision (lower is better) |

### Attitude

| Readout | Source | Description |
|---|---|---|
| Roll | `ATTITUDE` | Bank angle in degrees |
| Pitch | `ATTITUDE` | Nose up or down in degrees |
| Yaw | `ATTITUDE` | Heading from the IMU |

### Radio link

| Readout | Source | Description |
|---|---|---|
| RSSI and remote RSSI | `RADIO_STATUS` | Local and remote signal strength |
| Noise and remote noise | `RADIO_STATUS` | Local and remote noise floor |
| RX errors | `RADIO_STATUS` | Receive error count |
| TX buffer | `RADIO_STATUS` | Transmit buffer use |

### EKF

The EKF fuses sensor data into a position and velocity estimate. Mission Control shows its variance ratios as bars: velocity, horizontal position, vertical position, compass and terrain. Green is good, yellow marginal, and red means the estimate has not converged; do not fly GPS-dependent modes until it clears.

### Vibration

| Readout | Source | Description |
|---|---|---|
| Vibe X, Y, Z | `VIBRATION` | Vibration per axis (m/s/s) |
| Clipping | `VIBRATION` | Accelerometer clipping counts |

<Warning>
Vibration above 30 m/s/s points to a mechanical problem. It degrades the EKF and can cause a flyaway. Check motor balance, props and mounting before flying.
</Warning>

## Telemetry deck

The deck expands below the Flight tab readout. Use its controls to expand it, customise it, or **DETACH** it into its own window. It has four pages:

| Page | Default cells |
|---|---|
| Flight | REL ALT, AIRSPD, GSPD, CLIMB, ROLL, PITCH, YAW, WIND |
| Link | RSSI, REM RSSI, NOISE, REM NOISE, RX ERR, TX BUF, GPS FIX, SATS |
| Power | BAT V, BAT A, WATTS, mAh, EST MIN, THR |
| Tuning | ROLL, PITCH, YAW, VIBE X, VIBE Y, VIBE Z, EKF VEL, EKF POS |

Each cell shows its current value with a border coloured by severity. Drag cells to reorder them, or pick a preset: Mapping, Cinematic, Long-range or Tuning. When a cell crosses its warning or critical threshold, a toast names the value.

## Health and alerts

The Flight tab's health block shows the sensor health grid (gyro, accelerometer, compass, barometer, GPS, and optical flow or rangefinder when fitted) with failing sensors highlighted.

Mission Control raises alerts for low battery, GPS loss, RC link loss, arm and disarm, waypoint and mission events, failsafes and errors. Battery thresholds default to a 30 % warning and a 20 % critical alert. Change them, and turn alert sounds on, in [Settings → Notifications](/mission-control/settings#notifications).

## Freshness

Telemetry is fresh for 2 seconds after the last sample. After 2 seconds it is stale, and after 5 seconds it is lost: readouts show `--` instead of a value that may be wrong, and the readout shows **link silent**.

## Storage

Each channel keeps roughly the last 60 seconds in a ring buffer (for example 600 attitude samples at 10 Hz) and discards the oldest samples as new ones arrive. Recorded flights live in the Logs tab; see [Flight logs](/mission-control/flight-logs).
