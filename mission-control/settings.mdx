Settings hold Mission Control's own preferences, separate from each node's configuration (for that, see [Node configuration](/mission-control/node-configuration)). Open them with the gear in the top bar. Settings are stored in this browser; signed in, your preferences also sync to your account.

## Pages

The **GCS Settings** navigation lists ten pages:

| Page | Route | What it holds |
|---|---|---|
| **General** | `/config` | Jurisdiction, units, connection, demo mode, location, setup wizard, language and, in the desktop app, About |
| **Operator & Aircraft** | `/config/operator` | Pilot, organisation, insurance, aircraft, battery and equipment registries |
| **Input Devices** | `/config/input` | Controllers, Bluetooth, browser gamepad calibration, Skill bindings |
| **DroneCAN** | `/config/can` | CAN bus setup, node browser and bus tools |
| **Video** | `/config/video` | Current resolution |
| **Notifications** | `/config/notifications` | Sounds, alert thresholds, popups, changelog notifications |
| **Theme** | `/config/theme` | Theme and accent colour |
| **Data** | `/config/data` | Offline map tiles |
| **Flash Tool** | `/config/firmware` | Firmware flashing, see [Flash Tool](/mission-control/flash-tool) |
| **Extensions** | `/config/plugins` | Fleet-wide overview of installed extensions and the registry |

## General

| Setting | Default | Notes |
|---|---|---|
| **Regulatory Jurisdiction (optional)** | Not set | Picking one also sets units to that jurisdiction's default. |
| **Units** | Metric (m, km/h, °C) | Or Imperial (ft, mph, °F). |
| **Auto-connect on startup** | On | |
| **Auto-reconnect on disconnect** | On | |
| **Demo Mode** | Off, unless the build sets demo mode | Simulates telemetry to explore without a flight controller. |
| **Show My Position on Map** | Off | Uses browser geolocation. Your position stays in this browser and is never sent to a server. |
| **Re-run Setup Wizard** | | Runs the first-launch wizard again. |

Jurisdictions:

| Jurisdiction | Default units | Registration label |
|---|---|---|
| DGCA | Metric | UIN |
| FAA | Imperial | FAA N-number |
| CASA | Metric | CASA ID |
| EASA | Metric | EASA Operator ID |
| CAA UK | Metric | Operator ID |
| CAAC | Metric | UAS Registration |
| JCAB | Metric | DIPS ID |
| TCCA | Metric | RPAS Registration |

The registration label appears on the drone's Flight tab info card.

**Language**: choose from 16 languages: English, Hindi, Gujarati, Kannada, Marathi, Punjabi, Tamil, Telugu, Chinese, French, German, Indonesian, Japanese, Korean, Portuguese and Spanish. The interface switches without a reload.

**About** (desktop app only): **Check for updates** asks GitHub for a newer release now, instead of waiting for the next start. See [Desktop app updates](/mission-control/desktop-app#updates).

## Operator & Aircraft

Registries used for compliance exports and for the pilot, aircraft and loadout snapshot saved with each flight:

- **Pilot**, **Organisation**, **Insurance** and **Defaults** (default jurisdiction).
- **Aircraft**: name, registration, manufacturer, model, serial and Remote ID serial, vehicle type, category, maximum take-off mass, airworthiness and maintenance dates.
- **Batteries**: label, serial, chemistry, cell count, capacity, C rating and cycles. Retire or delete a pack.
- **Equipment**: propeller, motor and ESC sets, cameras, gimbals, payloads, frames and RC transmitters, with hours and flights. Mark an item inspected or retire it.

The battery and equipment you pick under **Loadout** on the Flight tab come from these registries.

## Input Devices

The page title is **Controllers**.

- **Devices** (with an agent connected): controllers attached to the ground station agent. **Scan Bluetooth** pairs a new one; **Set as primary** picks the controller that sends sticks.
- **Paired Bluetooth devices**: **Forget** removes one.
- **Browser Input**: controllers attached to this browser through the Web Gamepad API. Turn **Stick control** on, run **Calibrate**, choose the **Stick mode** (Mode 2, throttle on the left stick, by default; or Mode 1), and tune **Deadzone** and **Expo Curve**.
- **Skill & Keyboard Bindings**: loadout presets and the key and gamepad button for each Skill slot.

How stick control is gated and what the default bindings are: [Cockpit and Skills](/mission-control/cockpit#gamepad-and-stick-control).

## DroneCAN

**CAN Configuration** for the connected flight controller:

- **Bus setup**: CAN1, CAN2 and SLCAN passthrough, with **Save to FC**, **Write to flash**, **Reload from FC** and **Reboot FC**.
- **Node browser**: detected DroneCAN nodes.
- **Per-node params**: read and write a node's parameters.
- **Bus monitor**: raw MAVLink frames and decoded DroneCAN transfers.
- **Diagnostics**: bus diagnostics.
- **Test utilities**: node ping, manual frame inject, node-ID conflict scanner, ESC sweep, GPS fix snapshot and compass stream.

With no drone selected, the page asks you to connect a flight controller. Flash firmware to a CAN node from the [Flash Tool](/mission-control/flash-tool).

## Video

Shows the current resolution. Bitrate, codec and resolution are set per node, on the node's **Agent → Cameras** page. The transport is chosen in the video card's switcher; see [Video feed](/mission-control/video-feed).

## Notifications

| Setting | Default |
|---|---|
| **Enable audio alerts** | Off |
| Volume | 70 % |
| Alert sounds: Low Battery, GPS Lost, RC Link Lost, Arm / Disarm, Waypoint & Mission, Failsafe & Errors | All on (play only with audio alerts on) |
| **Battery warning threshold** | 30 % (10 to 50) |
| **Battery critical threshold** | 20 % (5 to 30, must be below the warning threshold) |
| **Alert popup duration** | 5 seconds (or 3, 10, or never dismiss) |
| **Show changelog notifications** | On |

**Reset seen entries** shows past changelog entries again.

## Theme

Pick a theme from the searchable list. The default is **Dark**.

- Core: Dark, Light and Mono.
- Solarized: Solarized Dark and Solarized Light.
- Dark themes: Dracula, Catppuccin Mocha, Catppuccin Frappé, Nord, Gruvbox Dark, One Dark, Tokyo Night, Rosé Pine, Monokai, Kanagawa, Synthwave '84 and GitHub Dark.
- Light themes: Catppuccin Latte and Gruvbox Light.
- Mid-tone: Ayu Dark, Ayu Mirage and Everforest Dark.

**Accent Color**: Blue (default), Green, Amber, Red, Lime, Purple, Pink, Cyan or Orange.

## Data

Download and manage offline map tiles for flying without internet.

## Flash Tool and Extensions

- **Flash Tool** opens the firmware flasher. See [Flash Tool](/mission-control/flash-tool).
- **Extensions** is a read-only overview of what is installed across the fleet, grouped per node, plus the registry browser. Installs happen per node from the node's **Agent → Extensions** page. An extension's detail page shows a **Failure reason** field when a LAN-paired node has stopped or refused it. See [Install extensions from Mission Control](/mission-control/installing-plugins).

The Parameters tab has its own column settings; see [Parameters](/mission-control/parameters).
