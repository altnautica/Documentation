The **Parameters** tab of a node gives direct access to every parameter on its flight controller. Open the node and click **Parameters**, or press `Ctrl+K` (`⌘K` on macOS) and search for a parameter name to jump straight to it.

<Frame caption="Parameters tab with the toolbar, column settings and the Options column.">
  ![Parameters tab listing parameters with Export, Export QGC, Compare and Write to FC in the toolbar](/images/mission-control/parameters.png)
</Frame>

The tab needs a connected flight controller. A progress bar shows the download as the parameter list arrives.

If the link drops parameters and the download does not finish, the tab still lists what arrived and shows **N of M received. Retry missing** in the header. Click **Refresh** to download the list again. A partial list is never cached as the flight controller's parameter set.

## Columns

| Column | Shown by default | Content |
|---|---|---|
| Index | Yes | Parameter index |
| Name | Yes | Parameter name, for example `ARMING_CHECK` |
| Value | Yes | Current value. Click to edit; enum parameters use a dropdown |
| Range | Yes | Valid minimum and maximum |
| Units | Yes | Units such as %, m or m/s |
| Options | Yes | Named values for enum and bitmask parameters |
| Description | No | What the parameter does |
| Type | No | Data type |

Use the column settings button in the toolbar to show or hide columns. Hover a parameter for its full description, range, default and options from the built-in ArduPilot and PX4 metadata.

## Search and filters

The search box matches parameter names and descriptions, ignoring case. Typing `BATT` shows the battery parameters.

| Filter | Shows |
|---|---|
| **Modified** | Parameters you have edited in this session but not written to the flight controller |
| **Non-Default** | Parameters whose value differs from the firmware default. **View diff** opens a full comparison against the defaults |
| **Favorites** | Parameters you have starred |

## Edit and write

1. Click a value and enter the new value. The row is marked as changed.
2. Click **Write to FC (N)**, where N is the number of changed parameters. The button shows progress while writing.
3. **Revert** discards unsaved edits without touching the flight controller.

If the aircraft is armed, writing opens the **Vehicle is armed** confirmation and you click **Write Anyway** to send the changes. **Reset to Default** (every parameter back to factory defaults) is disabled while armed.

<Warning>
Some parameter changes need a reboot of the flight controller before they apply. Armed writes take effect immediately. See [Safety](/operations/safety).
</Warning>

## Export, compare and restore

| Action | What it does |
|---|---|
| **Export** | Downloads every parameter as a Mission Planner `.param` file (`NAME,VALUE` per line) |
| **Export QGC** | Downloads a QGroundControl `.params` file |
| **Compare** | Loads a `.param` or `.params` file and compares it with the flight controller. Select the rows to apply and write them |

Example `.param` file:

```text
ARMING_CHECK,1
BATT_CAPACITY,5200
BATT_MONITOR,4
GPS_TYPE,1
```

To clone a configuration between identical aircraft, export from one, then use **Compare** on the other and write only the rows that differ. The Firmware panel also has parameter backup and restore around a flash. See [Flash Tool](/mission-control/flash-tool#back-up-and-restore-parameters).

File layouts are described in [Mission file formats](/mission-control/file-formats#parameter-files).
