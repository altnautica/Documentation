<Note>
ADOS uses "pairing" for three separate things. A ground station normally needs the first two.

- **Mission Control pairing** gives one Mission Control owner an API key for the node. See [Pairing](/drone-agent/pairing).
- **Air-link pairing** (WFB-ng bind) exchanges radio keys between a drone and a ground station. See [WFB-ng pairing](/drone-agent/wfb-pairing).
- **Mesh pairing** joins a relay to a receiver in a ground mesh. See [Build a mesh](/ground-agent/mesh-setup#mesh-pairing).
</Note>
