An Android phone or tablet connects to a ground station like any other client: over the [Wi-Fi access point](/ground-agent/wifi-ap) or a [USB tether](/ground-agent/usb-tether). Chrome needs no install. The Android GCS app (Android 10 and later) adds native video and discovers agents on the network for you. See [Android GCS](/android/overview) and [Install the Android GCS](/android/install).

## Connect

<Steps>
  <Step title="Join the access point or plug in USB">
    Join `ADOS-GS-<id>` (read the passphrase as described in [The AP passphrase](/ground-agent/wifi-ap#the-ap-passphrase); the LCD shows a join QR code), or connect a USB-C data cable on Android 11 and later.
  </Step>
  <Step title="Handle the no-internet prompt">
    See [No internet on the access point](#no-internet-on-the-access-point).
  </Step>
  <Step title="Open the node">
    **Chrome:** open one of the addresses below. **Android GCS app:** the app finds agents on the local network, so you do not type an address.
  </Step>
</Steps>

Over the access point:

<GsEndpoints host="192.168.4.1" />

Over USB tether, the host is `192.168.7.1` instead.

## Android GCS app or Chrome

| | Android GCS app | Chrome |
|---|---|---|
| Video | Native WebRTC (WHEP) with hardware decode; MediaCodec for direct radio streams | WebRTC in the browser |
| Finding the node | Discovers agents on the local network | Type the address |
| Gamepad | Android input devices, sent to the flight controller as `MANUAL_CONTROL` at 25 Hz | Browser Gamepad API in the on-box cockpit |
| Install | APK, see [Install the Android GCS](/android/install) | Nothing to install |

<Warning>
Stick control from the app moves the aircraft. Read [Safety](/operations/safety) before flying with a gamepad.
</Warning>

## No internet on the access point

During first-time setup, the ground station answers Android's connectivity check with a redirect, so the sign-in sheet opens on the setup wizard. Once setup is complete it stops answering those checks, and Android marks the network "No internet".

1. Choose "Stay connected" on the notification.
2. If Android keeps switching to mobile data, open the network's settings and turn off automatic switching to mobile data (some phones call it "Smart network switch" or "Wi-Fi assistant").

Over USB tether, Android does not run this check.

## Internet through the ground station

The access point is a local network by default; your phone cannot reach the internet through it. To change that, turn on uplink sharing (Mission Control node panel, **Network**, or `PUT /api/v1/ground-station/network/share_uplink`). Background app data then counts against a cellular data cap, if the node has a modem. See [Uplink matrix](/ground-agent/uplink-matrix#uplink-sharing).

## Bluetooth gamepads in Chrome

Chrome's Gamepad API works in the on-box cockpit with a few conditions:

- Use the full Chrome browser, not an in-app WebView.
- Load the page from the ground station's private address (`http://192.168.x.x`).
- Press any button to register the controller.

## Phone as a receiver

The Android GCS app can also receive a drone's radio link directly on the phone. The ground station issues and approves those phone-receiver invites through `/api/v1/ground-station/wfb/invite`. See [Android GCS](/android/overview).
