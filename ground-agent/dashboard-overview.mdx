A ground station runs the same Drone Agent dashboard on port `8080` as a drone, with ground-station pages in place of the drone pages. Opening it, the dashboard PIN, the layout and the profile rules are on the [Agent dashboard overview](/drone-agent/dashboard-overview#open-the-dashboard).

<Frame caption="Home on a ground station in the direct role.">
  ![Ground dashboard Home with status tiles, charts, Video and WFB Receive panels](/images/ground-agent/dashboard/home.png)
</Frame>

## Ground-station pages

| Page | Route | Roles |
| --- | --- | --- |
| [WFB Receive](/ground-agent/dashboard-receive) | `/receive` | every role |
| [Display & Joystick](/ground-agent/dashboard-io) | `/io` | every role |
| [Mesh](/ground-agent/dashboard-mesh) | `/mesh` | relay, receiver |
| [Sources](/ground-agent/dashboard-mesh#sources-receiver-role) | `/sources` | receiver |

The top bar's profile badge reads `ground_station · <role>`. The role (direct, relay or receiver) is set in **Settings → Profile**; see [Settings](/drone-agent/dashboard-settings#profile).

## Ground-only surfaces

- **Phone receivers** on the Pairing page: approve a phone after matching its key fingerprint. See [Pairing](/drone-agent/dashboard-pairing#phone-receivers-ground-station).
- **Settings → Display:** the active kiosk display and the panels this board supports.
- **Enter Cockpit:** the banner on Home opens the full-screen cockpit at `/cockpit`. An attached HDMI kiosk opens the same cockpit at `/cockpit/?kiosk=1`; see [HDMI kiosk](/ground-agent/hdmi-kiosk).
