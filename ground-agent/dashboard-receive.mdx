WFB Receive is a ground-station page at `/receive`: WFB-rx adapter, channel, link quality, and FEC counters. Home shows the same card.

## Fields

The **WFB Receive** card carries a state badge (`active`, `ready`, `connecting`, `error` or `disabled`) and these rows:

| Field | Shows |
| --- | --- |
| interface | the receive adapter |
| channel | the channel number and its frequency in MHz |
| rssi | received signal strength in dBm |
| snr | signal-to-noise ratio, when reported |
| noise | noise floor, when reported |
| bitrate | receive bitrate |
| packet loss | lost packets in percent: under 1% is normal, under 5% is a warning, higher is an error |
| FEC | `N ok · M fail`: blocks the forward error correction recovered and failed |
| restarts | receive pipeline restarts, once non-zero |

## Empty state

When the state is `disabled`, or `error` with no interface, the card reads "WFB-rx is not running. Plug in an RTL8812EU dongle and set the channel in Settings". The agent starts the receive pipeline automatically when an adapter and a channel are both present. The dashboard's Settings has no radio section; set the channel from Mission Control or see [WFB-ng](/drone-agent/wfb-ng).

## Data source

`GET /api/wfb`, every 2 s.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Packet loss stays high">
    Check the antennas and the distance to the drone, and compare rssi and snr. A rising FEC fail count means the link loses more than the error correction can repair. See [Ground Agent troubleshooting](/ground-agent/troubleshooting).
  </Accordion>
</AccordionGroup>
