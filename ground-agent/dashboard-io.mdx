Display & Joystick is a ground-station page at `/io`: HDMI kiosk display, joystick / gamepad assignment, and Bluetooth pairings for this ground station. **Refresh** reloads all three cards.

<Frame caption="Display & Joystick with the kiosk on, no gamepad attached and a Bluetooth scan running.">
  ![Ground dashboard Display and Joystick page with the Kiosk display, Gamepads / joysticks and Bluetooth cards](/images/ground-agent/dashboard/io.png)
</Frame>

## Kiosk display

The **Kiosk display** card shows:

| Field | Shows |
| --- | --- |
| kiosk | on or off |
| resolution | the kiosk output resolution |
| target | the URL the kiosk opens (`default` is the on-box cockpit) |

See [HDMI kiosk](/ground-agent/hdmi-kiosk) to change it.

## Gamepads / joysticks

The live controllers the ground station sees. The current primary carries a `primary` badge; each other controller has a **Make primary** button. With none attached the card reads "No game controllers attached. Plug in a USB joystick or pair a Bluetooth controller below."

## Bluetooth

**Paired** lists paired devices as connected or paired. Press **Scan**: the station listens for 8 seconds, then lists **Found nearby** devices, each with a **Pair** button. A successful pair reports "Paired and connected."

## Data sources

| Endpoint | Used for |
| --- | --- |
| `GET /api/v1/ground-station/display` | Kiosk display |
| `GET /api/v1/ground-station/gamepads` | Gamepads / joysticks |
| `PUT /api/v1/ground-station/gamepads/primary` | **Make primary** |
| `GET /api/v1/ground-station/bluetooth/paired` | Paired |
| `POST /api/v1/ground-station/bluetooth/scan` | **Scan** |
| `POST /api/v1/ground-station/bluetooth/pair` | **Pair** |

## Troubleshooting

<AccordionGroup>
  <Accordion title="Gamepad does not appear">
    Plug the controller in again, or pair it over Bluetooth, then press **Refresh**. If it still does not appear, check [Peripherals](/drone-agent/dashboard-peripherals) and restart `ados-input` from [Diagnostics](/drone-agent/dashboard-diagnostics).
  </Accordion>
  <Accordion title="Paired, but the device did not connect">
    Wake the controller or put it back in pairing mode, then scan and pair again.
  </Accordion>
</AccordionGroup>
