The ADOS Drone Agent publishes its reusable Rust code as separate crates on crates.io. All of them live in the [`crates/` workspace](https://github.com/altnautica/ADOSDroneAgent/tree/main/crates#published-crates) of the agent repository. The platform crates speak the agent's wire; the standalone crates have no ADOS dependency and work in any project.

## Platform

| Crate | What it does | Add it | Docs |
|---|---|---|---|
| [`ados-protocol`](https://crates.io/crates/ados-protocol) | Wire contracts for the agent: IPC framing, plugin RPC envelope and capability tokens, the vision frame bus, MSP and MAVLink helpers | `cargo add ados-protocol` | [docs.rs](https://docs.rs/ados-protocol) |
| [`ados-sdk`](https://crates.io/crates/ados-sdk) | Build Rust plugins for the agent: async IPC client, plugin context, hardware driver traits and lifecycle runner | `cargo add ados-sdk` | [docs.rs](https://docs.rs/ados-sdk) |
| [`ados-tracker`](https://crates.io/crates/ados-tracker) | Single-object visual tracker: Kalman motion model with appearance re-identification, YOLOv8 head decoding and OSNet embeddings | `cargo add ados-tracker` | [docs.rs](https://docs.rs/ados-tracker) |

## Versioning

- **Platform crates move in lockstep with the agent.** `ados-protocol`, `ados-sdk` and `ados-tracker` carry the agent version, so `ados-sdk` X.Y.Z speaks the wire of agent X.Y.Z. Pin the major.minor of the agent you target.
- **Standalone crates follow their own semver.** They started at 0.1.0 and bump only when they change.

Any change to a published crate's packaged files ships with a version bump. To build an agent plugin, start with the [Rust SDK guide](/developers/sdk-rust).
