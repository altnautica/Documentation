The ADOS Drone Agent publishes its reusable Rust code as separate crates on crates.io. All of them live in the [`crates/` workspace](https://github.com/altnautica/ADOSDroneAgent/tree/main/crates#published-crates) of the agent repository. The platform crates speak the agent's wire or read its board profiles; the standalone crates have no ADOS dependency and work in any project.

**Platform (versioned with the ADOS Drone Agent)**

| Crate | What it does | Add it | Docs |
|---|---|---|---|
| [`ados-protocol`](https://crates.io/crates/ados-protocol) | Wire contracts of the ADOS Drone Agent: IPC framing, plugin RPC envelope, capability tokens and the vision frame bus. | `cargo add ados-protocol` | [docs.rs](https://docs.rs/ados-protocol) |
| [`ados-sdk`](https://crates.io/crates/ados-sdk) | Write Rust plugins for the ADOS Drone Agent: IPC client, plugin context, driver traits and lifecycle runner. | `cargo add ados-sdk` | [docs.rs](https://docs.rs/ados-sdk) |
| [`ados-vision`](https://crates.io/crates/ados-vision) | Single-object visual tracker: Kalman motion model, appearance re-identification and YOLOv8 head decoding. | `cargo add ados-vision` | [docs.rs](https://docs.rs/ados-vision) |
| [`ados-gpio`](https://crates.io/crates/ados-gpio) | Drive status buzzers and LEDs on Linux GPIO lines, with bounded software-PWM beep patterns. | `cargo add ados-gpio` | [docs.rs](https://docs.rs/ados-gpio) |
| [`ados-hal-probe`](https://crates.io/crates/ados-hal-probe) | Find out what a board's hardware can really do by probing it, plus bundled board profiles. | `cargo add ados-hal-probe` | [docs.rs](https://docs.rs/ados-hal-probe) |

## Versioning

- **Platform crates move in lockstep with the agent.** `ados-protocol`, `ados-sdk`, `ados-vision`, `ados-gpio` and `ados-hal-probe` carry the agent version, so `ados-sdk` X.Y.Z speaks the wire of agent X.Y.Z. Pin the major.minor of the agent you target.
- **Standalone crates follow their own semver.** They started at 0.1.0 and bump only when they change.

Any change to a published crate's packaged files ships with a version bump. To build an agent plugin, start with the [Rust SDK guide](/developers/sdk-rust).
