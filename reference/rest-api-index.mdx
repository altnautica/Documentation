This index is generated from the Drone Agent source. Its input is the agent's
own route table, which a test in the agent keeps in step with the router, so
every row here is a route the agent actually serves. For request and response
shapes, authentication, and worked examples, see the
[REST API guide](/drone-agent/rest-api).

How to read the tables:

- A `{name}` segment matches one path segment; `{*name}` matches the rest of the path.
- Method `WS` marks a route that answers only a WebSocket upgrade.
- **unauthenticated by design** marks a route that answers with no credential at all.
- **relay-forbidden** marks a route the agent refuses when the request arrives through the cloud relay, so it only works from the local network.
- A blank note means the route takes the normal auth of the listener that serves it.
