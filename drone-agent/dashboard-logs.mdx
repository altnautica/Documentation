Logs is a shared page at `/logs`: a live tail of the agent's structured logger. Filter by level or logger name.

<Note>
This page reads the Black Box log store, which is off by default. Turn on `logging.store.enabled` to fill it; otherwise use `journalctl -u <unit>` over SSH. See [Black Box](/drone-agent/black-box).
</Note>

<Frame caption="Logs on a node with the store off, the default.">
  ![Agent dashboard Logs page with the Level and Logger contains filters above the notice that the logging store is off, with the journalctl command and the setting that turns the store on](/images/drone-agent/dashboard/logs.png)
</Frame>

## Controls

- **Level:** any, DEBUG, INFO, WARNING, ERROR or CRITICAL. These are the agent log levels; the agent's own verbosity is set in [Settings → Advanced](/drone-agent/dashboard-settings#advanced) (default info).
- **Logger contains:** a text filter on the logger name.
- **Pause** and **Resume:** stop and restart the live tail.

The counter on the right shows the number of rows with `(live)` while streaming or `(poll)` on the fallback.

## Rows

Each row shows time, level, logger name and message.

## Data sources

| Endpoint | Used for |
| --- | --- |
| `GET /api/logs/stream?level=&service=` | live tail (Server-Sent Events) |
| `GET /api/logs?limit=200&level=&service=` | fallback every 2 s when the stream fails, and every 30 s otherwise to learn whether the store is answering |

## Troubleshooting

<AccordionGroup>
  <Accordion title="No rows">
    "The logging store is off or not answering, so this node has no log history to show." means the store is off (the default) or down; the page shows how to turn it on, and the system journal stays the log of record. "no log entries match the filter." means the filter matches nothing. "no log entries yet." means the store is on but has no rows yet.
  </Accordion>
</AccordionGroup>
