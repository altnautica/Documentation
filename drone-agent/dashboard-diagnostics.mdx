Diagnostics is a shared page at `/diagnostics`: system metrics, agent services, and recovery actions.

<Frame caption="Diagnostics with the Agent services list populated.">
  ![Agent dashboard Diagnostics page with CPU, Memory, Disk and Temp tiles and the Agent services list](/images/drone-agent/dashboard/diagnostics.png)
</Frame>

## System tiles

| Tile | Shows |
| --- | --- |
| CPU | percent used and the core count |
| Memory | percent used and used / total MB |
| Disk | percent used and used / total GB |
| Temp | the first temperature sensor only, with its name |

## Agent services

Each row shows the unit name, its state badge and **Restart**. The confirm **Restart `<unit>`?** says "The service drops out and ados-supervisor brings it back. Dependent services may also restart." **Refresh** reloads the list. The unit list itself is on [systemd services](/drone-agent/systemd-services).

## Reboot board

**Reboot board** sits at the top right. The confirm **Reboot the board?** explains that the agent shuts down all services and asks the kernel to reboot; the dashboard reconnects once the board is back up (typically 30 to 60 seconds).

<Warning>
While the vehicle is armed, rebooting and restarting link services are refused. See [Safety interlocks](/drone-agent/dashboard-overview#safety-interlocks) and [Safety](/operations/safety).
</Warning>

## Data sources

| Endpoint | Used for |
| --- | --- |
| `GET /api/system` | system tiles, every 5 s |
| `GET /api/services` | Agent services, every 8 s |
| `POST /api/services/{name}/restart` | **Restart** |
| `POST /api/v1/setup/reboot` | **Reboot board** |

## Troubleshooting

<AccordionGroup>
  <Accordion title="Couldn't reach the service inventory">
    The agent did not answer `GET /api/services`. Check `journalctl -u ados-supervisor` over SSH, then press **Retry**.
  </Accordion>
  <Accordion title="Couldn't query systemd from the agent">
    `systemctl` is missing or blocked, so the inventory is unavailable; running services may still be alive. Check `journalctl -u ados-supervisor`.
  </Accordion>
  <Accordion title="A service keeps failing">
    Filter the [Logs](/drone-agent/dashboard-logs) page by its logger name, or read `journalctl -u <unit>` over SSH.
  </Accordion>
</AccordionGroup>
