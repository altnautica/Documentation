Peripherals is a shared page at `/peripherals`: registered peripheral manifests with live connection state. Plug a known device and the agent picks it up automatically. Raw hardware detection lives in Home → Hardware.

<Frame caption="Peripherals with a registered device.">
  ![Agent dashboard Peripherals page with a peripheral card showing its state badge and detail line](/images/drone-agent/dashboard/peripherals.png)
</Frame>

## Card fields

Each registered peripheral is one card:

- a status dot and the display name;
- a state badge: connected, disconnected, missing, error or unknown;
- the peripheral id;
- a detail line: `transport · kind · vendor · category`;
- the description;
- `last seen` with the time since the agent last saw it.

The page refreshes every 8 s; **Refresh** reloads it at once.

With nothing registered the page reads "No peripherals registered." Manifests come from pip packages and `/etc/ados/peripherals/*.yaml`; install a peripheral plugin and it appears here.

## Data sources

| Endpoint | Used for |
| --- | --- |
| `GET /api/v1/peripherals` | the card list |

Also available, not used by this page: `GET /api/v1/peripherals/{peripheral_id}` and `POST /api/v1/peripherals/{peripheral_id}/action`. A peripheral action is refused while the vehicle is armed (see [Safety interlocks](/drone-agent/dashboard-overview#safety-interlocks)).
