The Drone Agent ships 21 board profiles. Each profile is a YAML file that tells the agent which SoC it runs on, which buses are available, which video encoders exist, and what hardware is attached.

<Note>
**Ready to install?** Use the [Flash Tool in Mission Control](/mission-control/flash-tool). Pick your board from the catalog, then copy the install command for it.
</Note>

## Board profiles

The agent identifies the board from an optional `/etc/ados/board_override`, the device-tree compatible string and model, then `/proc/cpuinfo`. If nothing matches, it falls back to `generic-arm64` on ARM hosts or `generic-x86_64` on x86 hosts. The detection order is on [HAL and tiers](/drone-agent/hal-and-tiers#board-detection).

<SupportedBoards />

Every board installs the agent on top of its stock vendor OS through the Flash Tool's install command. The video codecs column lists hardware codecs from the profile; a board without a hardware encoder falls back to software encoding. The tier column is the profile's default compute tier, which only matters for extensions that set a minimum tier. See [HAL and tiers](/drone-agent/hal-and-tiers#default-tier).

## Recommended boards

### For development and testing

**Radxa ROCK 5C Lite**

A strong development and flight board: 6 TOPS NPU, VPU H.264/H.265 encode, up to 16 GB RAM. The GPU may be absent on the Lite bin; the agent probes it at runtime.

<Note>
The ROCK 5C Lite uses a 31-pin 0.3 mm Radxa FPC connector for MIPI CSI, not the standard Raspberry Pi ribbon. Check camera compatibility before purchasing.
</Note>

### For ground station use

**Raspberry Pi 4B (4 GB or 8 GB)**

The Pi 4B is the recommended ground station board. It has proven RTL8812EU driver support for WFB-ng, a 40-pin GPIO header for the status display and front-panel buttons, USB ports for Wi-Fi adapters, Gigabit Ethernet, and HDMI output for kiosk mode. Its board profile declares the front-panel button pins. See [Ground Agent supported hardware](/ground-agent/supported-hardware).

### For production builds

**Rockchip RK3576 (reference design)**

A production-oriented SoC with a 6 TOPS NPU, H.265 4K60 encode, multiple MIPI CSI inputs, Mini-PCIe for a 4G modem, and USB 3.0. One board profile covers both air and ground configurations.

### For budget builds

**Rockchip RV1126B**

A good option for cost-sensitive builds: hardware ISP, H.264/H.265 encode and a 2 TOPS NPU in a small package.

## Wi-Fi adapter for WFB-ng

The long-range video link needs a Wi-Fi adapter that supports monitor mode and packet injection. The supported chipset is the **RTL8812EU**. An RTL8812AU adapter is a different chip and is not the supported driver.

| Adapter | Chipset | TX power (hardware spec) | Interface | Notes |
|---|---|---|---|---|
| LB-LINK BL-M8812EU2 | RTL8812EU | 29 dBm (800 mW) | USB 2.0 | Recommended. Small form factor (about 25 g). |

The agent starts at 5 dBm and clamps to `tx_power_max_dbm` (15 by default); see [WFB-ng TX power](/drone-agent/wfb-ng#tx-power).

The adapter runs in monitor mode on the 5.8 GHz band. It does not use normal Wi-Fi association. It broadcasts raw 802.11 frames using the WFB-ng protocol with forward error correction (FEC). Expect 1-3 km on stock antennas; much longer with a high-gain ground antenna and clear line of sight.

<Warning>
The RTL8812EU needs an out-of-tree kernel driver. The installer builds it automatically on supported boards (skip it with `--no-rtl-driver` on a node with no long-range radio). On a custom kernel, make sure the kernel headers are installed so the driver can build.
</Warning>

## Adding a new board

If your board is not in the list, the agent falls back to `generic-arm64` (or `generic-x86_64`), tiered from detected RAM. To add a profile for it, follow [Adding a new board](/drone-agent/hal-and-tiers#adding-a-new-board).
